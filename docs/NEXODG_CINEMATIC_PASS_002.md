# NEXODG — Cinematic Pass 002

## Objetivo
Elevar `/studio-lab` desde una narrativa procedural 2D a una experiencia espacial continua, manteniendo el lenguaje fundacional negro + blanco + `#00D9D9`.

## Cambios de esta pasada
- La apertura temporal queda sostenida hasta que el usuario inicia el scroll.
- El inicio del scroll funde la apertura con la narrativa principal, evitando un vacío entre tiempo e interacción.
- La escena de conexiones incorpora sensación de cámara, dos anillos orbitales y colapso físico de WhatsApp / Datos / CRM / IA / Web / Personas / Automatizaciones hacia el núcleo NEXO.
- `SISTEMA` se convierte en un momento espacial: wireframe cube 3D, scan line, glow y aumento de escala controlado por scroll.
- `DISEÑO → TECNOLOGÍA → IA` deja de ser sólo recambio tipográfico. Cada disciplina es ahora un plano espacial con profundidad, perspectiva y lenguaje gráfico propio.
- Los tres planos convergen en una única composición antes del cierre `CONSTRUIMOS SOLUCIONES`.
- Se amplió el recorrido a `940vh` para dar respiración a las transformaciones.
- Cursor y scroll siguen funcionando como inputs complementarios.
- Reduced motion mantiene las transiciones esenciales sin desplazamientos 3D innecesarios.
- El contenido explícito posterior se rediseñó para continuar el lenguaje de sistema, con tres capacidades y hover cyan de alto contraste.

## Decisiones
- No incorporar todavía WebGL ni assets 3D pesados: esta pasada busca comprobar que la dirección espacial funciona con CSS transforms + Motion antes de aumentar peso y complejidad.
- Mantener el home productivo sin cambios hasta superar QA visual desktop/mobile del laboratorio.
- El siguiente salto debe concentrarse en uno o dos momentos hero de calidad superior, no en agregar animaciones indiscriminadamente.

## Próxima pasada sugerida
1. Afinar ritmo y legibilidad en desktop/mobile sobre capturas reales.
2. Introducir un objeto hero o secuencia visual propia de NexoDG en la transición `SISTEMA → DISEÑO/TECNOLOGÍA/IA`.
3. Diseñar casos/proyectos como continuidad narrativa, evitando cards de portfolio convencionales.
4. Revisar performance, reduced motion y densidad visual antes de promover a `/`.
